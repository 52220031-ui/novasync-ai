# NovaSync AI

## About the Project

NovaSync AI is a modern web application designed to help students manage their studies, health, and daily activities in one place.

## Live Demo

https://novasync-ai.vercel.app/

## GitHub Repository

https://github.com/52220031-ui/novasync-ai

## Features

- Modern Home Page
- AI Demo Chatbot
- Health and Activity Tracker
- Study Support
- About Us Page
- Services Page
- Contact Form
- Responsive Design
- User-Friendly Interface

## Technologies Used

- React JS
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- React Router
- Vite
- Git and GitHub

## Installation

1. Clone the repository:

   git clone https://github.com/52220031-ui/novasync-ai.git

2. Open the project folder:

   cd novasync-ai

3. Install dependencies:

   npm install

4. Run the project:

   npm run dev

## Project Purpose

This project was developed for educational purposes to demonstrate React development, reusable components, state management, and responsive web design.
