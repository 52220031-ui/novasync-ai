# Screenshots

Save your UI screenshots in this folder using these exact file names so the main README displays them:

| File | What to capture |
|------|-----------------|
| `home.png` | Home page (desktop) |
| `about.png` | About page |
| `services.png` | Services page |
| `tracker.png` | Health Tracker with a few entries logged |
| `chat.png` | AI Chat with a conversation |
| `contact.png` | Contact form (ideally showing validation errors) |
| `mobile.png` | Any page at phone width (Chrome DevTools > device toolbar) |

Tip: in Chrome press F12, then Ctrl+Shift+P, type "screenshot" and choose "Capture full size screenshot".
